# Electric Field Simulation

## Project Description

This project is an interactive simulation designed to visualize the behavior of conductors and insulators in the presence and absence of an electric field. The simulation demonstrates how charges are distributed within different materials, how free electrons move in conductors, and how polarization occurs in insulators when an external electric field is applied.

The application provides a visual representation of fundamental electrostatic concepts, allowing users to observe the differences between conductive and insulating materials under varying electric field conditions.

## Objectives

- Visualize charge distribution in conductors and insulators.
- Demonstrate electron movement in conductive materials.
- Illustrate polarization effects in insulating materials.
- Compare material behavior with and without an applied electric field.
- Provide an interactive learning experience for understanding electrostatic principles.

## Features

- Interactive electric field control.
- Adjustable electric field strength.
- Material selection between conductor and insulator.
- Real-time charge redistribution visualization.
- Electron movement simulation for conductors.
- Polarization visualization for insulators.
- Reset functionality to restore the initial state.
- Dynamic status display showing simulation parameters.

## Technologies Used

- HTML
- CSS
- JavaScript

## Working Principle

When an electric field is applied, free electrons in a conductor move in response to the field, resulting in charge separation and redistribution across the material. In contrast, charges within an insulator remain bound to their atoms but experience slight displacement, producing polarization. The simulation visually represents these effects and updates the system dynamically based on user interaction.

## Educational Value

This simulation serves as an educational tool for understanding the fundamental differences between conductors and insulators in electrostatics. It helps visualize concepts that are often difficult to observe directly, including charge movement, induced charge distribution, and electric polarization.

## Usage

1. Open the simulation in a web browser.
2. Select the desired material type.
3. Adjust the electric field strength using the provided controls.
4. Observe charge behavior and polarization effects.
5. Reset the simulation at any time to return to the initial state.

## Conclusion

This project demonstrates the behavior of conductors and insulators under electric fields through an interactive and visual approach. By simulating charge redistribution, electron movement, and polarization effects, it provides a practical understanding of key electrostatic concepts.
